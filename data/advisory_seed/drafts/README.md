# Draft seed data — NOT loaded

Rows copied from the MoA guideline tables so an expert can verify them and move
them into `../approved_products.csv` and `../dosage_rules.csv`.

- `*_as_written` columns are copied exactly from the source table (page cited).
- `latin_name_guess` and `target_key_guess` are transliterations / mappings made
  while drafting. Check them; they are not authoritative.
- Active ingredient, registration number, pre-harvest interval, re-entry time
  and rain-free period are NOT in the source tables and must come from the EAA
  registered pesticide list and the product label.
- The loader never reads this folder.
